Scroll

From video to scroll experience in three steps.

The “3D” you just scrolled through is a pre-rendered clip. The engine turns it into images and plays them forward and backward as you scroll.

01

Make a clip

Any video: AI-generated, 3D render, drone footage, screen capture. This demo was rendered with tools/render_demo.py.

02

Extract frames

build_frames.py runs ffmpeg to write a desktop and a mobile WebP set, plus a manifest.

03

Scrub on scroll

A sticky canvas stays pinned while a tall track scrolls. Progress picks the frame; easing smooths it.

Drop it into any page.

No build step, no dependencies. Include one file and describe your scenes.

<!-- a tall track holding a sticky pin with the canvas -->
<div id="track" style="height:800vh">
  <div style="position:sticky;top:0;height:100svh">
    <canvas id="stage" style="width:100%;height:100%"></canvas>
    <h2 id="hello">Hello</h2>
  </div>
</div>

<script src="scrollframe.js"></script>
<script>
  new Scrollframe({
    track: '#track',
    canvas: '#stage',
    manifest: 'frames/manifest.json',
    overlays: [{ el: '#hello', from: 0.1, to: 0.4 }]
  });
</script>

Built to be fast and boring in the best way.

Progressive loading

Loads the first frame, then every 16th, then fills in. The page goes live after about 7% of the frames.

Mobile frame set

Phones automatically get smaller images. Less data, same feel.

Sleeps off-screen

The render loop pauses when the track isn’t visible, saving battery.

Accessible

Real DOM text for SEO, honors prefers-reduced-motion, and has an image alt label.
